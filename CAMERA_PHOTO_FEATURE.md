# 📸 Camera Photo Feature

I have implemented the requested "Camera Snapshot" feature. This allows the application to capture a single photo from the webcam at set intervals, separate from video recording.

## what Changed

1.  **New Capture Module**: Created `capture/capture_photo.py` with logic to safely capture a single frame from the webcam.
2.  **Configuration**: Added settings for `camera_photo_enabled`, `interval`, `start_time`, etc.
3.  **Settings UI**: Added a new row "Camera Snapshot (Image)" in the "Monitoring Features" section of the Settings page.
4.  **Scheduler**: Added a new background task to execute the photo capture.

## Availability
*   **Plan**: This feature is included in the **Base Plan** (bundled with Screenshot permissions).
*   **Priority conflicts**: If a Video Recording and a Photo Snapshot are scheduled at the same time, the **Video Recording takes precedence**. The photo capture will be skipped to allow the video to record.

## How to Enable

1.  Go to **Dashboard** -> **Settings**.
2.  Scroll down to **Monitoring Features**.
3.  Find "**Camera Snapshot (Image)**".
4.  Check the **Enable** box.
5.  Set the **Interval** (e.g., 60 minutes).
6.  Click **Save Settings**.
7.  **Restart Monitoring** (Stop/Start) or Restart the App.

## Output
*   The photos will be saved as `.jpg` files in the `captures` folder.
*   They will be named: `DeviceName - CameraPhoto - Timestamp.jpg`.
*   They will be included in the Bundled Report email just like other data.
